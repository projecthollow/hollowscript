# Contributing

Development of this project is closed. Source is published per release, the
roadmap is decided by the maintaining organisation, and pull requests are not
accepted. This keeps the project able to move quickly on a language and
runtime that is still being defined, without the overhead of reviewing and
maintaining outside changes against a specification that is itself still
settling.

Issues describing a bug or a specification question are welcome. Please do
not open a pull request; it will not be merged, however small.
