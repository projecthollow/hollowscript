HollowScript in the browser

This page loads the WebAssembly build of the virtual machine and runs compiled bytecode through it. The browser never sees source: there is no parser and no checker in this build, and the verifier refuses bytecode that does not hold to the rules before a single instruction of it runs.

Build the module first, from the repository root: cargo build -p hollowscript-wasm --release --target wasm32-unknown-unknown, then serve this directory alongside target/wasm32-unknown-unknown/release/hollowscript_wasm.wasm.

Compile a program to bytecode with hollowscript build program.hws -o program.hsb and choose it here.
